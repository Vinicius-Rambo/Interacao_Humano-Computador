## Conteúdo da aula
Aula: 06/11 - 13/11

Criar uma solução de técnologia focada em iteração utilizando uma TV BOX B13, tablet ou Smartphone.

- **Grupo 1:** Felipe, Matheus Cardozo, Vitor
- **Grupo 2:** Vinicius, Gabriel, Alisson, Amanda
- **Grupo 3:** Manoel, Carlos, Thiago F, Matheus Maia
- **Grupo 4:** Thiago, Breno.

**Lembrete do professor:** 
- O foco da disciplina é a **interação**: pensem em quem vai usar, testem com pessoas reais e melhorem a interface a partir do que observarem.
- A TV box tem pouca memória (2 GB), então prefiram soluções leves.
- Projetos com câmera ou voz precisam respeitar a privacidade (LGPD): após os testes vamos analisar a autorização de gravar dados das pessoas.

# Correções feitas: 

- [Linux](https://github.com/gabclima/b13/blob/main/TUTORIAL.md): A instalação do Linux na TV Box altera os dados de boot no pendrive. Então temos que gerar o pendrive a cada instalação.
- Clone do robo assistente do [GitHub](https://github.com/marcosroquerosa/robo-assistente-b13): foi corrigido o instalador, para instalar o pacote android-sdk-platform-tools-common, que traz as permissões do USB para celulares.
