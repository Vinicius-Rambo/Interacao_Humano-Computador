# Interface (IHC)

A **interface** é toda a porção de um sistema interativo com a qual o usuário mantém contato (físico ou conceitual) durante a interação. 

## Tipos de Contato
- **Físico/Motor:** Ações realizadas através de hardwares e dispositivos de entrada (teclado, mouse, microfone, VR). Permite ao usuário agir ativamente.
- **Perceptivo/Visual:** Recepção de reações do sistema através de dispositivos de saída (monitor, alto-falantes). Permite a participação passiva.

## O Papel do Projeto de Interface
A interface determina as possibilidades de interação: o que o usuário pode fazer, como e em que ordem.
Muitas vezes, a interface é vista pelo usuário como o próprio sistema, por ser o único meio de contato disponível.
