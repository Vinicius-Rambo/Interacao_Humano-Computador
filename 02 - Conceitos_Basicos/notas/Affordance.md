# Affordance

**Affordance** é o conjunto de características de um objeto que revela aos usuários como ele pode ser operado ou manipulado. Sugere a possibilidade de ação baseada na aparência.

- *Exemplo Físico:* Uma maçaneta sinaliza visualmente se a porta deve ser empurrada ou puxada.
- *Exemplo Digital:* Um botão de comando na tela sinaliza que pode ser pressionado/clicado.

## Falsas Affordances
Ocorrem quando o design de uma interface passa a impressão de que o sistema funciona de um jeito, mas ele reage de outro. 
- *Exemplo:* Usar uma caixa com aparência de input de texto apenas para exibir uma mensagem estática. 

Isso deve ser evitado pelos designers, pois causa confusão, efeitos colaterais indesejados e prejudica a experiência.
