# Interação (IHC)

A **interação** é tudo o que ocorre quando uma pessoa e um sistema computacional se unem para realizar tarefas com um objetivo específico.
Ela pode ser definida como um processo de comunicação entre pessoas, que é mediada por sistemas computacionais. Envolve processos complexos como:
- Manipulação
- Comunicação
- Conversa
- Troca
- Influência mútua

# Perspectivas de Interação
Segundo Kammersgaard (1988), existem quatro perspectivas principais para compreender a interação usuário-sistema:

1. **Sistema:** 
   - *Visão:* O usuário é visto como outro computador/máquina.
   - *Foco:* Transmissão de dados, eficiência, redução de erros e tempo. Entradas padronizadas e rígidas (ex: linhas de comando).
2. **Parceiro de Discurso:** 
   - *Visão:* O computador é visto como uma pessoa capaz de raciocinar e inferir (Inteligência Artificial).
   - *Foco:* Conversa entre usuário e sistema em linguagem natural. Avalia-se a adequação da interpretação e geração de respostas.
3. **Ferramenta:** 
   - *Visão:* O computador é um instrumento para realizar tarefas e manipular materiais.
   - *Foco:* Facilidade de uso e relevância das funcionalidades oferecidas. O sucesso depende da destreza do usuário.
4. **Mídia:** 
   - *Visão:* O computador é um canal de comunicação.
   - *Foco:* Comunicação entre pessoas (e-mail, fóruns, redes sociais) ou comunicação unilateral do designer para o usuário (mensagens de ajuda, organização da interface). Qualidade do entendimento mútuo.
