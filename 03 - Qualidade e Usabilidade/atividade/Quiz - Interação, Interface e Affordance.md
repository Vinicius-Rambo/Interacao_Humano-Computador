
**1. Em IHC, o contexto de uso inclui quais elementos relevantes para a interação do usuário com um sistema?** 
**Resposta:** O momento de utilização e os ambientes físico, social e cultural.

**2. Qual definição melhor caracteriza a interação usuário-sistema?** 
**Resposta:** Tudo o que acontece quando pessoa e sistema se unem para realizar tarefas visando a um objetivo.

**3. Segundo Kammersgaard (1988), quais são as quatro perspectivas de interação usuário-sistema?** 
**Resposta:** Sistema, parceiro de discurso, ferramenta e mídia.

**4. Na perspectiva de sistema, como a interação usuário-sistema é principalmente compreendida?** 
**Resposta:** Como transmissão de dados entre usuário e sistema.

**5. Na perspectiva de sistema, qual é o principal objetivo?** 
**Resposta:** Aumentar a eficiência e a transmissão correta de dados, reduzindo o tempo de interação e os erros.

**6. Na perspectiva de parceiro de discurso, o sistema interativo deve assumir qual papel?** 
**Resposta:** Um participante da interação capaz de raciocinar, fazer inferências e tomar decisões.

**7. Na perspectiva de parceiro de discurso, qual meio de comunicação usuário-sistema é destacado?** 
**Resposta:** Linguagem natural.

**8. Na perspectiva de ferramenta, como o sistema interativo é considerado?** 
**Resposta:** Como um instrumento que auxilia o usuário a realizar tarefas.

**9. Na perspectiva de ferramenta, quais fatores de qualidade são destacados como mais evidentes?** 
**Resposta:** Relevância das funcionalidades e facilidade de uso.

**10. Na perspectiva de mídia, o sistema interativo é visto principalmente como:** 
**Resposta:** Um meio pelo qual pessoas se comunicam umas com as outras.

**11. Qual é a principal diferença entre as perspectivas de mídia e de parceiro de discurso?** 
**Resposta:** A perspectiva de mídia envolve comunicação entre pessoas, enquanto a de parceiro de discurso envolve uma conversa usuário–sistema.

**12. O que é a interface de um sistema interativo?** 
**Resposta:** Toda a porção do sistema com a qual o usuário mantém contato físico ou conceitual.

**13. Por que o contexto de uso deve ser considerado no projeto de uma interface?** 
**Resposta:** Porque uma resposta sonora pode ser pouco útil em um ambiente barulhento.

**14. Em uma interface gráfica, o que representa a affordance de um botão de comando?** 
**Resposta:** A possibilidade de pressioná-lo para acionar uma operação do sistema.

**15. Qual das situações abaixo representa uma possível falsa affordance em uma interface?** 
**Resposta:** Uma caixa de texto com aparência editável utilizada apenas para apresentar uma mensagem que não pode ser alterada.
